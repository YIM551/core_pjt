# Gitmoji Cheatsheet

- `:heavy_plus_sign: build:` dependency addition
- `:arrow_up: build:` dependency upgrade
- `:arrow_down: build:` dependency downgrade
- `:hammer: build:` build/toolchain configuration
- `:rocket: deploy:` deployment configuration
- `:construction_worker: ci:` CI workflow change
- `:green_heart: ci:` CI repair
- `:building_construction: infra:` local or runtime infrastructure
- `:truck: rename:` rename or move
- `:lock: security:` security hardening
- `:zap: perf:` performance improvement
- `:wrench: chore:` local tooling or maintenance

Select the primary intent. If a change has multiple primary intents, split the
commit instead of combining prefixes.
