## 검증 범위

자동 테스트·빌드·실제 로컬 모델 추론·PostgreSQL HTTP 회귀를 수행한다. 개인의 카메라·마이크를 자동으로 켜서 검증하지 않는다. 합성 음성·공개 시험 음성과 계산 fixture는 실행 경로 검증용이며 한국어 면접 전체 정확도의 증거는 아니다.

각 기능의 원리·모델 및 검증 결과는 [로컬 음향 분석](local-audio-analysis.md), [영상 보정](../frontend/docs/local-media.md), [실행 방법](studio-local.md)을 참고한다. 공개 백업에는 소스·테스트·설치 지침만 담고 사용자 자료·녹음·DB·인증정보·모델 파일은 포함하지 않는다.
