## 운영 원칙

- 모델 API는 로컬 주소만 허용합니다. 모델·WASM은 같은 서버에서 제공하고 녹음·문서를 외부 API에 전송하지 않습니다.
- 기본 미디어 보관 시간은 24시간이며, 별도 워커를 실행해야 요청이 없는 시간에도 정리와 작업 복구가 수행됩니다.
- 음향 진단 불가, 얼굴·손 미검출, 모델 실패를 점수 0으로 바꾸지 않습니다. CTC는 score:null, calibrated:false이며 음소 발음 평가가 아닙니다.
- 현재 데이터 모델은 단일 임시 계정 인증을 계승합니다. 실제 다중 사용자 로그인·배포 인증은 별도 작업입니다.
- 완료 리포트는 revision별 불변 본문을 조회하며, 삭제 요청 시 관련 보관본도 개인정보 삭제를 반영합니다.
- 자동 소음 억제는 브라우저 지원과 실제 장치 설정에 의존합니다. 배경 화자는 별도 로컬 분리 모델로 처리하며 등록 화자 판정이 불확실하면 해당 구간을 제외합니다.

## 확인된 실행 결과

- 프론트: 테스트 48개 통과, Vite 프로덕션 빌드 성공, 최종 독립 검토 `0 findings`.
- 백엔드: 실제 PostgreSQL HTTP 회귀를 포함해 `STUDIO_TEST_POSTGRES=1` 전체 120개 테스트 통과, Alembic 0009 적용, 최종 독립 검토 `0 findings`.
- 로컬 모델: 기존 Qwen3-4B GGUF 질문 생성 및 내용 평가 성공. faster-whisper-small CPU/int8 로딩 성공, 무음 입력 0개 발화 구간 반환.
- 브라우저: 임시 세션 인증, 지원자료 DB 저장, 선택 자료에 관한 질문 생성, 텍스트 답변 선저장·내용 평가·강점·개선점 리포트까지 확인.
- 실제 HTTP 음성 통합: Windows 한국어 TTS로 만든 합성 음성을 WebM/Opus로 변환하고 2개 청크를 전송하여 봉인 → 로컬 전사 → 확정 → 내용 평가 → 최종화 → 리포트까지 통과. 해당 합성 예시에서 21어절/14.02초, 89.9어절/분을 반환했습니다. 실제 사람의 발화 정확도 검증 결과는 아닙니다.
- 실제 음성 파일 검사에서 faster-whisper 1.2.1과 PyAV 19의 호환 문제를 확인해 로컬 요구사항에 PyAV 16.0.1을 고정했습니다. 전사에는 기술 용어 오인식이 관찰되어 확인·수정 절차를 유지합니다.
- 실제 PostgreSQL에서 요청 트랜잭션과 BackgroundTasks 사이 잠금 대기를 재현하고, 백그라운드 등록 전 commit과 HTTP 회귀 테스트로 보완했습니다.

전체 v0.3의 정확도·환경별 수락 기준을 모두 통과한 제품으로 표시하지 않습니다. 구현된 경로와 실제 모델 품질 검증의 완료 여부를 분리합니다.

## 이번 추가 검증

- 실제 로컬 음향 모델과 PostgreSQL을 포함한 120개 회귀 테스트 통과. 프론트 48개 테스트 및 프로덕션 빌드 통과. 양쪽 최종 독립 검토는 `0 findings`.
- 공개 영어 사람 음성의 단독·혼합 양성 대조군에서 등록 화자 유지, 타 화자 단독 입력 제외를 확인했습니다. 8kHz 분리 모델에 맞춰 등록 음성 비교 대역을 일치시켰으며 판정 임계값은 유지했습니다. 한국어 현장 정확도를 입증한 시험은 아닙니다.
- 모델 revision은 설치 예상값으로 표시하며 실제 로드한 파일의 해시 검증을 주장하지 않습니다.
- 전체 요구사항 24개와 남은 P1 URL 가져오기·비교 추세/내보내기, 상세 제스처 의미 분석 등의 범위는 [v0.3 점검표](v03-audit.md)를 확인하세요.
