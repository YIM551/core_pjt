## 자주 겪는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| 대시보드 화면이 안 뜸 / 웹캠이 안 켜짐 | html 파일을 직접 엶 / 카메라 권한 거부 | 서버 실행 후 <http://127.0.0.1:8000> 으로 접속, 권한 허용 |
| 로봇이 안 움직인다 | 2일차 서버를 띄움 (응답에 tool 없음) / describe 선택 | `page39` 서버 실행, 서버 창의 `[tool]` 줄 확인 |
| 방향을 말했는데 되묻는다 | 방향어 정규식이 못 잡음 | 강의자료 도전 문제 2 |
| 몇 칸 가다가 멈춘다 | 벽 · 격자 경계 | 정상. 시뮬레이터 이동 경로 로그 확인 |
| `API_검증.py` 가 서버에 연결할 수 없다고 함 | 서버를 안 띄움 | 터미널 1 에서 서버 먼저 |
| `ggml-cuda ... CUDA error` 로 서버 종료 | torch(GPU) 와 llama.cpp 가 한 프로세스에서 충돌 | 서버 코드가 CPU 로 고정한다 ― 다른 설정이 덮어쓰지 않았는지 확인 |
| 첫 요청만 오래 걸림 | 모델 지연 로딩 | 정상. 두 번째부터 빨라진다 |

옵션은 모든 스크립트에서 `-h` 로 확인할 수 있다.
