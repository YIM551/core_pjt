# page31 ― 조건분기

> 강의자료 **31쪽** (코드) / **32쪽** (동작 결과)

조건 분기를 코드로 보장한다 ― 근거 없는 move 는 ask 로, 되묻기 뒤 칸 수는 코드가 이어 준다

## 무엇을 하는가

- [R3] 질문의 방향어 · 이전 턴 질문 · 손 제스처 중 근거가 없으면 move → ask
- [R5] ask 가 args 에 기억한 칸 수를, 방향만 답한 다음 턴에 이어 쓴다
- 시스템 프롬프트는 실습 2-1 그대로 ― 코드만 더한다

## 실행

```bash
cd page31_조건분기
python 조건분기.py
python 조건분기.py --question "위 2칸 가"    # 도전 문제 2
```

## 확인 포인트

- 8/8 ― 두 문항은 'R3 가 바꿈' 으로 표시된다
- 되묻기 2턴 : '저쪽으로 2칸 가' → ask(steps=2) → '왼쪽' → move(left, 2)
- '위 2칸 가' 는 ask 로 잘못 막힌다 ― 도전 문제 2 에서 고친다
