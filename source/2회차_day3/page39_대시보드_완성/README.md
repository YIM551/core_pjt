# page39 ― 대시보드 완성

> 강의자료 **39쪽** (코드) / **40쪽** (동작 결과)

2일차 대시보드 서버의 /api/llm-answer 를 도구 호출로 바꿔, 웹캠 질문으로 시뮬레이터 로봇을 움직인다

## 무엇을 하는가

- A1 ~ A4 (화면 · 제스처 파일 · YOLO · VLM) 는 2일차 서버 그대로
- A5 : decide_tool = 실습 2-1 의 파서 + 실습 3-1 의 규칙 (R1 ~ R5)
- 서버 창에 [tool] 한 줄로 질문 → 도구 → 인자 → 문장이 찍힌다

## 실행

```bash
cd page39_대시보드_완성
python 대시보드_완성.py      # 띄워 둔다
# 브라우저에서 http://127.0.0.1:8000 → 대시보드 › 로컬 PC 에서 질문 → 시뮬레이터 탭 확인
```

## 확인 포인트

- '앞에 뭐가 있어?' → describe, '오른쪽으로 3칸 가' → 로봇이 오른쪽으로 3칸
- '저쪽으로 2칸 가' → [추가 정보 요청] → '아래' → 아래로 2칸
- 벽이나 격자 경계에 막히면 그 자리에서 멈춘다 ― 시뮬레이터 이동 경로 로그 확인
- html 파일을 직접 열면 동작하지 않는다 ― 반드시 서버 주소로 접속

## 이 폴더에 생기는 것

- 실행결과.txt ― 실제 실행 출력
- 실행화면.png ― 대시보드 (웹캠 대신 samples/sample.jpg)
- 실행화면_시뮬레이터.png ― 시뮬레이터 (벽 배치는 캡처용 고정 시드)
