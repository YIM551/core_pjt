# page21 ― 도구선택

> 강의자료 **21쪽** (코드) / **22쪽** (동작 결과)

LLM 이 질문의 의도를 파악해 도구(move / describe / ask)와 인자를 JSON 으로 고른다

## 무엇을 하는가

- 인식 결과는 2일차 대시보드 실측값 (person 3개, bus 1개 / 버스 앞에 두 명)
- 질문 8개의 기대 도구 · 인자와 비교해 채점한다
- 파서(parse_tool_call)가 도구와 인자의 모양을 보장한다 (R1 · R2)

## 실행

```bash
cd page21_도구선택
python 도구선택.py
python 도구선택.py --rule "..."                # 규칙 한 줄 추가 (도전 문제 1)
python 도구선택.py --question "위 2칸 가"
```

## 확인 포인트

- 6/8 ― 설명 2 · 이동 4 문항은 정답
- '저쪽으로 가' · '버스 있는 쪽으로 가' 는 되묻지 않고 move(right, 1) 로 추측한다
- 규칙을 프롬프트에 더해도 그대로 6/8 (도전 문제 1)
