# 2회차 웹 대시보드 화면 (완성본)

2일차 · 3일차 실습 서버가 함께 쓰는 프런트다. **수정하지 않는다** ― 서버만 만든다.

| 파일 / 폴더 | 내용 |
|---|---|
| `index.html` | 대시보드 화면 (연동 · 대시보드 · 시뮬레이터 탭) |
| `mediapipe/` | 브라우저 제스처 인식 번들 (`vision_bundle.mjs`, `wasm/`). 모델 파일 `gesture_recognizer.task` 는 서버가 `models\` 에서 내준다 |

## 여는 법

html 파일을 더블클릭하면 **동작하지 않는다** (API 호출 · 웹캠 · 제스처 인식이 모두 서버 주소 기준).
실습 서버를 띄운 뒤 브라우저에서 <http://127.0.0.1:8000> 으로 연다.

| 서버 | 되는 것 |
|---|---|
| `2회차_day2/page45_대시보드_서버` | 웹캠 · 스냅샷 · YOLO 박스 · VLM 설명 (LLM 칸은 오류가 정상) |
| `2회차_day2/page64_대시보드_LLM연결` | + LLM 답변 (설명만, 로봇은 움직이지 않음) |
| `2회차_day3/page39_대시보드_완성` | + 도구 호출 ― 시뮬레이터 로봇 이동, 되묻기 |

## 화면이 서버에 기대하는 것

`../2회차_day3/API_설계.md` 에 번호(A1 ~ A5)로 정리되어 있다.
이번 회차에는 **대시보드 › 로컬 PC** 탭과 **시뮬레이터** 탭만 쓴다 (연동 탭은 3회차 라즈베리파이용).
