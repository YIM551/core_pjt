## 확인 포인트

- `--quick` 22/22, 전체 98/98 (기기 없이)
- `--device` 를 붙여 마지막 줄 `전체 N/N PASS` 를 확인한다
- 11월 20일 기존 Pi 배포본과의 연동은 **205/205 PASS**였다. [기존 배포 측정](실행결과_20261120.txt)
- 최종 D5 배포 후 측정한 추론 시간, R9 오분류 수정 전후 결과, 실물 관찰과 서비스 중단·복구 결과를 함께 기록했다. [최종 배포 실기기 검증](최종배포_실기기검증_20261120.txt)
