# page37 ― 기동 순서 · 설치 확인

> 강의자료 **34쪽** (최종 배선) · **35쪽** (실습 1-5 센서 테스트 5종) / **37쪽** (실습 1-6 기동 순서)  ·  `AI코어프로젝트_3회차_DAY3_r2.pptx`  ·  실행 위치: **PC**

강의자료 37쪽의 확인 순서(D1 → D2 · D3 → D4 → D5 → PC 중계)를 한 번에 돌리고, 실패한 단계에서 멈춰 고칠 곳을 알려 준다

## 무엇을 하는가

- 앞 단계가 안 되면 뒤는 의미 없다 ― FAIL 이면 거기서 멈추고 해당 실습 폴더를 가리킨다
- D5 를 한 번 호출해 모델을 미리 올려 둔다 ― 이후 시나리오가 7 ~ 11초 안에 돈다
- `--ptt` 를 주면 PTT 로 말해 D4 의 seq 가 오르는지까지 본다

## 실행

```bash
# 라즈베리파이: ~/venv/bin/python3 ~/camera_server.py (또는 F106 서비스)
# PC 터미널 1: python ..\page30_음성경로_통합\대시보드_음성통합.py
python 기동_점검.py --device <PiIP>
python 기동_점검.py --device <PiIP> --ptt
```

## 확인 포인트

- `전 단계 PASS` 가 나오면 연동 탭에 IP 를 등록하고 page40 로
- 2단계 `oled=unavailable` 은 오류가 아니다(200, R6) ― 그래도 화면이 안 나오면 SPI · venv · 배선
- 기기 서버가 꺼져 있으면 1단계에서 멈춘다 (실행결과.txt)

## 이 폴더의 파일

- `기동_점검.py`
- `실행결과.txt` ― 라즈베리파이 서버가 꺼진 상태에서 PC 로 실행한 출력 (PC 실측)
- `기대출력.txt` ― 라즈베리파이 실물에서 나와야 하는 출력 형식 (코드의 출력 문구 · 강의자료 기준, 실측 아님)
