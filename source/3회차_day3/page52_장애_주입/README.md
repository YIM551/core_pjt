# page52 ― F303 장애 주입

> 강의자료 **51쪽** (장애 유형) / **52쪽** (실습 4-1) · **53쪽** (동작 결과) · **54 ~ 55쪽** (도전 문제 2)  ·  `AI코어프로젝트_3회차_DAY3_r2.pptx`  ·  실행 위치: **PC**

기기를 일부러 끊어 보고, 대시보드가 멈추지 않고 그 기기 요청만 502 로 실패하는지 한 줄씩 관찰한다

## 무엇을 하는가

- 2초마다 영상(A6) · 음성(A9) · 로컬 PC(A1) 상태를 한 줄로 찍고, 바뀌면 '← 바뀜' 표시
- `--ask` 로 기기 탭 질문 하나를 보내 기기 LLM 경로의 502 · 지연을 본다 ― 이때 history 는 유지된다 (R6)
- 타임아웃은 설계다 ― 연결 3초(꺼진 기기는 빨리 실패) · 영상 읽기 10초 · LED · OLED 5초 · 기기 LLM 120초 · 음성 폴링 3초

## 실행

```bash
python 장애_관찰.py --device <PiIP>              # 띄워 둔 채 아래 장애를 하나씩
# ① 라즈베리파이 서버 Ctrl+C  ② 다시 실행  ③ 공유기에서 Pi Wi-Fi 잠시 끊기  ④ 서버 재시작 직후 첫 질문
python 장애_관찰.py --device <PiIP> --ask "왼쪽"
```

## 확인 포인트

- 서버를 끄면 영상 · 음성이 502 로 바뀌고 로컬 PC 는 '정상' 그대로
- Wi-Fi 를 끊으면 약 10초 뒤 스트림 종료 → 화면은 3초 뒤 재연결
- 기기 꺼짐 + `--ask` → 3초 안에 502 device_llm_unreachable, history 유지
- 서버 재시작 직후 첫 질문은 1분 가까이 ― 대시보드는 '처리 중 ― 첫 요청은 1분 가까이' 를 표시한다
- OLED 케이블을 뽑고 move → LED · 답변은 정상, OLED 만 미표시 (200, 오류 아님)
