# page44 ― F302 음성 되묻기 대화

> 강의자료 **43쪽** (두 갈래) / **44쪽** (실습 3-1) · **45쪽** (동작 결과) · **46 ~ 47쪽** (도전 문제 1) · **48쪽** ([참고] 더 생각해 볼 포인트)  ·  `AI코어프로젝트_3회차_DAY3_r2.pptx`  ·  실행 위치: **PC**

ask 되묻기와 제안(guess)에 음성으로 답해 move 로 이어 가고, 음성 · 텍스트 턴을 섞어도 history 가 이어지는지 본다

## 무엇을 하는가

- history 는 화면처럼 이 스크립트가 들고 있다가 매 요청에 싣는다 ― ask 면 이번 턴을 남기고, 최종 답이면 비운다 (R7)
- pending_steps · pending_guess 는 서버 변수가 아니라 history 의 직전 assistant 턴에서 읽는다 ― 서버를 재시작해도 이어진다
- '응' 의 범위 ― 응 · 어 · 네 · 예 · 그래 · 좋아 · 맞아 · ㅇㅇ · ok · yes
- 제안(guess)은 기기 LLM 이 방향을 추측했을 때만 나온다 ― 안 나오면 ② 는 건너뛴다

## 실행

```bash
python 되묻기_대화.py --device <PiIP>
python 되묻기_대화.py --device <PiIP> --ptt      # 음성 턴은 PTT 로
```

## 확인 포인트

- ① '저쪽으로 2칸 가' → ask → '왼쪽' → move(left, 2) · OLED LEFT
- ② '저쪽으로 2칸 가' → '오른쪽으로 갈까요?' → '응' → move(right, 2) · OLED RIGHT
- ③ 음성 ask 뒤 기기 탭 타이핑 '위' → move(up, 2) · OLED UP
- 최종 답 뒤 history 0개

## 이 폴더의 파일

- `되묻기_대화.py`
- `기대출력.txt` ― 라즈베리파이 실물에서 나와야 하는 출력 형식 (코드의 출력 문구 · 강의자료 기준, 실측 아님)
