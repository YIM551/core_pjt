# 기대 출력 ― 라즈베리파이 실물에서 나와야 하는 출력의 형식이다 (코드의 출력 문구 · 강의자료 수치 기준).
# 실측 기록이 아니므로 시간 · 인식 문장 · 장면 설명 · 숫자는 환경마다 다르다. <...> 는 환경마다 달라지는 값.

$ python 시나리오_실행.py --device <PiIP>

■ 앞에 뭐가 있어?
    텍스트  O  <8 ~ 11>s  describe {}
              OLED 그대로  ·  LED 없음  ·  '<장면 설명 두세 문장>'
    음성   O  <8 ~ 11>s  describe {}
              OLED 그대로  ·  LED 없음  ·  '<장면 설명 두세 문장>'
    R9  텍스트 · 음성 같은 tool · args : 같다

■ 오른쪽으로 3칸 가
    텍스트  O  <8 ~ 11>s  move {'direction': 'right', 'steps': 3}
              OLED RIGHT  ·  LED right  ·  '오른쪽으로 이동합니다.'
    음성   O  ...  (텍스트와 같다)
    R9  텍스트 · 음성 같은 tool · args : 같다

■ 왼쪽으로 1칸 가
    텍스트  O  ...  move {'direction': 'left', 'steps': 1}
              OLED LEFT  ·  LED left  ·  '왼쪽으로 이동합니다.'
    ...

■ 아래로 2칸 가
    텍스트  O  ...  move {'direction': 'down', 'steps': 2}
              OLED DOWN  ·  LED 없음  ·  '아래로 이동합니다.'
    ...

■ 오른쪽 2칸 가고 위로 1칸
    텍스트  O  ...  move {'direction': 'right', 'steps': 2} + then [{'direction': 'up', 'steps': 1}]
              OLED RIGHT → UP  ·  LED right  ·  '오른쪽 → 위 순서로 이동합니다.'
    ...

■ 저쪽으로 가
    텍스트  O  ...  ask {'steps': 1}            (기기 LLM 이 추측했으면 + 'guess': '<방향>')
              OLED 그대로  ·  LED 없음  ·  '어느 쪽으로 갈까요? 방향을 말하거나 손으로 가리켜 주세요.'
    ...
