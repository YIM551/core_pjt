# page40 ― F301 도구별 통합 시나리오

> 강의자료 **40쪽** (실습 2-1 시나리오 표) · **41쪽** (서버 로그) · **42쪽** (R9)  ·  `AI코어프로젝트_3회차_DAY3_r2.pptx`  ·  실행 위치: **PC**

같은 질문을 텍스트(기기 탭 타이핑)와 음성으로 보내 tool · args · OLED · LED 가 같은지 시나리오 표를 채운다

## 무엇을 하는가

- 텍스트 = source "device", 음성 = source "voice" ― 둘 다 기기 LLM 이 고르고 PC 가 같은 규칙을 적용한다 (R9)
- move 면 화면처럼 이동마다 A8(OLED) · A7(LED, 좌우만)을 2초 간격으로 호출한다 (R8)
- 인식 결과는 고정 문구 ― 도구 선택만 비교한다. 대시보드 기기 탭에서 같은 질문을 직접 해 보고 나란히 비교한다
- `--ptt` 를 주면 음성은 PTT 로 직접 말하고 A9 로 받은 글자를 쓴다

## 실행

```bash
python 시나리오_실행.py --device <PiIP>
python 시나리오_실행.py --device <PiIP> --ptt
python 시나리오_실행.py --device <PiIP> --no-output      # OLED · LED 는 건드리지 않는다
```

## 확인 포인트

- describe → OLED · LED 그대로, 장면 설명
- '오른쪽으로 3칸 가' → RIGHT · 오른쪽 LED · '오른쪽으로 이동합니다.'
- '아래로 2칸 가' → DOWN · LED 없음
- '오른쪽 2칸 가고 위로 1칸' → RIGHT → UP · LED 는 RIGHT 때만
- '저쪽으로 가' → ask, OLED · LED 그대로
- 텍스트 = 음성이 아니면 먼저 입력창(인식 글자)을 확인한다 ― STT 문제지 도구 선택 문제가 아니다
- 같은 문장을 로컬 PC 탭에 보내면 tool · args 는 같고 문구만 '오른쪽으로 3칸 이동합니다.' (R10)
