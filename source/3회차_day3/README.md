모든 스크립트는 PC 에서 돌린다. 서버 두 개를 먼저 띄운다.

```bash
# 라즈베리파이
~/venv/bin/python3 ~/camera_server.py          # 또는 sudo systemctl start camera-stream

# PC 터미널 1
cd page30_음성경로_통합
python 대시보드_음성통합.py

# PC 터미널 2
cd page37_기동_점검
python 기동_점검.py --device <PiIP>
```

**대시보드 기기 탭에서 직접 해 보는 것이 본 실습이다.** 폴더의 스크립트는 같은 요청을 터미널에서 다시 보내
결과표 · 검증 결과를 남기는 보조 도구다 (화면과 같은 A5 요청 · 같은 history 처리 · 같은 OLED · LED 호출 순서).

## 자주 겪는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| 시나리오가 1분 가까이 걸린다 | 기기 LLM 첫 요청 (모델 로딩) | `page37` 로 미리 올려 둔다 |
| 텍스트와 음성 결과가 다르다 | 음성 인식 글자가 다름 | 기기 탭 입력창 글자부터 확인 ― STT 문제 (2일차 심화 F205) |
| '응' 에 move 가 안 된다 | 직전 ask 에 제안(guess)이 없었다 | 방향으로 답한다 ― 제안은 기기 LLM 이 추측했을 때만 |
| 되묻기 뒤 방향만 말했는데 다시 묻는다 | 기기 탭 history 가 비었다 (새로고침 · 다른 탭) | 같은 기기 탭에서 이어서 |
| FAIL 번호를 어디서 찾나 | ― | A = PC 코드, D = 기기 서버 · 배선, R = 규칙 함수 (명세서 'API 및 규칙 명세' 표) |
| 서비스 실행 중 손으로 또 띄움 | 8080 포트 · 카메라 충돌 | `sudo systemctl stop camera-stream` 후 |

옵션은 모든 스크립트에서 `-h` 로 확인할 수 있다.
