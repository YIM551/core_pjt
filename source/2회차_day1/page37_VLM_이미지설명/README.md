# page37 ― VLM 이미지설명

> 강의자료 **37쪽** (코드) / **38쪽** (동작 결과)

VLM 을 올려 이미지를 한국어로 설명하게 한다

## 무엇을 하는가

- GGUF 본체 + mmproj 두 파일로 VLM 을 로드한다
- 이미지를 base64 로 넣고 한국어 설명을 받는다

## 실행

```bash
cd page37_VLM_이미지설명
python VLM_이미지설명.py --max-tokens 80
```

## 확인 포인트

- CPU 추론이라 1회에 약 90초 걸린다 ― 정상이다
- 이 시간이 전체 응답 시간을 지배한다는 것이 핵심 관찰이다
