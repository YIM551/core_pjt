# page28 ― YOLO 성능측정

> 강의자료 **28쪽** (코드) / **29쪽** (동작 결과)

모델 선정 근거가 될 숫자를 남긴다

## 무엇을 하는가

- 로딩 시간 / 추론 시간 10회 평균 / fps / 메모리 증가량을 측정한다
- 결과를 CSV 로 저장한다

## 실행

```bash
cd page28_YOLO_성능측정
python YOLO_성능측정_기록표.py --runs 10
```

## 확인 포인트

- PC마다 값이 다르다 ― 내 PC의 숫자를 남기는 것이 목적이다
- 3회차 발표에서 모델 선정 근거로 그대로 쓴다
