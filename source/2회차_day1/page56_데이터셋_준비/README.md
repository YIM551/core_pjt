# page56 ― 데이터셋 준비

> 강의자료 **56쪽** (코드) / **57쪽** (동작 결과)

파인튜닝용 데이터셋을 만들고 검증한다

## 무엇을 하는가

- --demo 로 실습용 미니 데이터셋(train 40 / val 10)을 생성한다

## 실행

```bash
cd page56_데이터셋_준비
python 데이터셋_준비와검증.py --demo
```
