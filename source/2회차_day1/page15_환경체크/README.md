# page15 ― 환경체크

> 강의자료 **15쪽** (코드) / **16쪽** (동작 결과)

설치가 끝났는지 5분 안에 확인한다

## 무엇을 하는가

- 설치된 패키지와 버전을 확인한다 (fastapi / ultralytics / llama_cpp 등)
- 추론 디바이스가 CPU 인지 GPU 인지 확인한다
- 모델 가중치 3개가 제자리에 있는지 확인한다

## 실행

```bash
cd page15_환경체크
python 환경체크_설치확인.py
```

## 확인 포인트

- 모든 줄이 OK 면 다음 실습으로 넘어간다
- MISS 가 하나라도 있으면 여기서 해결한다 ― 나중에 하면 실습 전체가 밀린다
