# page25 ― YOLO 첫추론

> 강의자료 **25쪽** (코드) / **26쪽** (동작 결과)

이미지 1장을 넣고 박스·클래스·확신도를 받아 본다

## 무엇을 하는가

- YOLO11n 으로 samples/sample.jpg 를 추론한다
- --sweep 을 붙이면 conf 0.1 / 0.25 / 0.6 을 한 번에 비교한다

## 실행

```bash
cd page25_YOLO_첫추론
python YOLO_첫추론.py --sweep
```

## 확인 포인트

- conf 를 낮추면 검출 수가 늘지만 오탐도 함께 는다
- conf 0.10 에서 오탐 skateboard 가 하나 더 잡히는지 확인한다
