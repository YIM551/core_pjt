# page23 ― 모델로딩 지연과락

> 강의자료 **23쪽** (코드) / **24쪽** (동작 결과)

동시 요청에도 모델이 딱 1개만 올라가는지 검증한다

## 무엇을 하는가

- 스레드 8개에서 동시에 get_yolo_model() 을 호출한다
- double-checked locking 으로 중복 로드를 막는다

## 실행

```bash
cd page23_모델로딩_지연과락
python YOLO모델_지연로딩과락.py
```

## 확인 포인트

- '서로 다른 모델 인스턴스: 1' 과 '실제 로드 횟수: 1' 이 나와야 한다
- 락을 빼면 로드 횟수가 2 이상으로 올라간다 ― 직접 지워 보고 비교해도 좋다
