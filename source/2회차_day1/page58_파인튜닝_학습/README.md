# page58 ― 파인튜닝 학습

> 강의자료 **58쪽** (코드) / **59쪽** (동작 결과)

사전학습 가중치에서 출발해 전이학습한다

## 무엇을 하는가

- yolo11n.pt 에서 시작해 우리 데이터셋으로 추가 학습한다
- epoch 마다 val mAP 가 어떻게 움직이는지 관찰한다

## 실행

```bash
cd page58_파인튜닝_학습
python YOLO_파인튜닝_학습.py --epochs 10
```

## 확인 포인트

- 먼저 page56_데이터셋_준비 를 실행해 dataset/ 이 있어야 한다
- 실측 : 10 epochs 에서 val mAP50 0.354 → 0.968 로 올라갔다
- 결과 가중치는 상위 폴더의 runs/ft_v1/weights/best.pt

## 이 폴더에 생기는 것

- ../runs/ (공용)
- 실행결과.txt ― 실제 실행 출력
