# page67 ― 음성 중계 A9

> 강의자료 **66쪽** (A9 폴링) / **67쪽** (실습 4-1) · **68쪽** (화면) · **69쪽** (동작 결과)  ·  `AI코어프로젝트_3회차_DAY2_r2.pptx`  ·  실행 위치: **PC**

PJT01 완성 서버에 A9 /api/voice-poll 을 더해, PTT 로 말하면 기기 탭 입력창이 자동으로 채워지고 전송되게 한다

## 무엇을 하는가

- 화면이 기기 탭이 열려 있는 동안 1초마다 A9 → 기기 D4 를 그대로 돌려준다 (타임아웃 3초)
- seq 가 이전보다 크고 text 가 비어 있지 않을 때만 새 발화 → 입력창 + 음성 배지 → source: "voice" 로 전송
- 처리 중이면 끝날 때까지 기다렸다 보낸다 (대기열 1칸)
- 기기 응답 형식(seq int · text str)까지 검사 ― 틀리면 502 invalid_device_response
- 매초 도는 폴링이라 연속 5회 실패했을 때만 '음성 ● 끊김' 을 표시한다
- 이 단계의 서버는 음성 질문도 아직 PC LLM 이 고른다 ― 기기 LLM 은 3일차 page22

## 실행

```bash
# 라즈베리파이: page63 기기 서버
python 대시보드_음성중계.py        # 기기 탭을 열어 두고 PTT 로 말한다

# 기기 없이 확인 (다른 터미널)
curl -i "http://127.0.0.1:8000/api/voice-poll?ip=192.0.2.1"
```

## 확인 포인트

- PTT 로 말하면 1초 안에 기기 탭 입력창이 채워지고 자동 전송된다
- '오른쪽으로 두 칸 가' → OLED RIGHT + 오른쪽 LED (PJT01 과 같다)
- ip 없음 → 400, 연결할 수 없는 IP → 502 device_unreachable
