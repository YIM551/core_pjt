## 오늘 만드는 것

**먼저 1일차에 못 다 한 대시보드 연동(A6 ~ A8 · R10 · API 검증)을 마친다** (강의자료 12 ~ 31쪽, `page15` · `page23` · `page29`).
그다음 PTT 버튼으로 말하면 **라즈베리파이가 듣고(whisper.cpp) 대시보드 입력창에 글자로 들어가 전송된다 (음성 중계까지).**
도구 선택은 그대로 PC LLM 이 한다. 기기 LLM(Qwen3-1.7B, D5) · 통합(R9) · API 검증은 **3일차로 옮겼다**.

```
PTT 누름 → arecord 녹음, 뗌 → whisper.cpp → 기기 /voice-text {seq, text} (D4)
화면이 1초마다 PC /api/voice-poll (A9) → seq 가 커지면 기기 탭 입력창 자동 입력 · 전송 (source: "voice")
A5 → PC LLM 이 도구 선택 → apply_rules (R1 ~ R5) → move 면 OLED · LED (1일차와 같다)
(3일차) A5 → 기기 /llm-infer (D5) → PC 가 다시 검사 (R9)
```

## 설치

- **PC** ― 새로 설치할 것이 없다.
- **라즈베리파이** ― `설치_명령어_기기_2일차.sh`. whisper.cpp 빌드(약 3분)는 수업 전에 시작해 둔다.

### 배선 추가분 (강의자료 46쪽 · 전원을 끄고 · 1일차 배선은 그대로)

| 장치 | 신호 | BCM GPIO | 물리 핀 |
|---|---|---|---|
| SPH0645 마이크 | 3V · GND | 3.3V · GND | 1 · 14 (빵판 − 레일에서 버튼과 공유, 5V 금지) |
| SPH0645 마이크 | BCLK · LRCL · DOUT | 18 · 19 · 20 | 12 · 35 · 38 (SEL 은 미연결 또는 GND) |
| PTT 버튼 | 한쪽 · 반대쪽 | 23 · GND | 16 · 14 (내부 풀업, 저항 없음) |

## 자주 겪는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| `arecord -l` 에 sndrpigooglevoi 가 없다 | config.txt 줄 앞에 `#` / 재부팅 안 함 | `dtparam=i2s=on` · `dtoverlay=googlevoicehat-soundcard` 후 재부팅 |
| `lgpio.error: 'bad event request'` | Pi 5 에서 gpiozero `Button` 이벤트 등록 실패 | `InputDevice` 폴링 (코드가 이미 그렇게 한다) |
| PTT 를 눌러도 seq 가 안 오른다 | 0.5초 미만 누름 / 버튼 배선 | 서버 로그 `PTT: 녹음 시작` 확인, page51 |
| seq 는 오르는데 text 가 빈다 | whisper 경로 · 모델 파일 / 무음 | 로그의 `STT: whisper 바이너리/모델을 찾을 수 없다` |
| 입력창이 자동으로 안 채워진다 | page67 이전 서버(A9 없음) | `page67` 이후 PC 서버 |
| 기기 탭 질문인데 OLED 가 안 바뀜 | describe · ask 는 출력하지 않는다 | 정상. move 일 때만 |

옵션은 모든 스크립트에서 `-h` 로 확인할 수 있다.
