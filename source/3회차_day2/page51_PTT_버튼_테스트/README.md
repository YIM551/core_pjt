# page51 ― PTT 버튼 ― 폴링 · 채터링 제거

> 강의자료 **50쪽** (폴링) / **51쪽** (실습 2-2) · **52쪽** (동작 결과)  ·  `AI코어프로젝트_3회차_DAY2_r2.pptx`  ·  실행 위치: **라즈베리파이**

PTT 버튼(GPIO 23)을 20ms 마다 읽고 연속 2회 같아야 눌림 · 뗌으로 확정한다 ― 기기 서버와 같은 판정

## 무엇을 하는가

- Pi 5 의 함정 ― gpiozero `Button` 은 이벤트 등록이 `lgpio.error: 'bad event request'` 로 실패한다 → `InputDevice` 폴링
- 내부 풀업 ― 버튼 반대쪽은 GND, 누르면 LOW(is_active True). 저항이 필요 없다
- 20ms × 2회 = 40ms 동안 같은 값이어야 확정 ― 기계식 스위치의 채터링을 거른다
- 0.5초 미만 누름은 기기 서버가 무시한다 (F205 · page63)

## 실행

```bash
~/venv/bin/python3 test_ptt.py
~/venv/bin/python3 test_ptt.py --seconds 30
```

## 확인 포인트

- 누를 때 '눌림', 뗄 때 '뗌 (n.n초)' 가 한 번씩만 찍힌다 (여러 번이면 채터링)
- 손을 대지 않았는데 '눌림' 이면 버튼 반대쪽이 GND 가 아니라 3.3V 에 꽂혔다
- 기기 서버가 GPIO 23 을 잡고 있으면 GPIO busy ― 먼저 끈다
