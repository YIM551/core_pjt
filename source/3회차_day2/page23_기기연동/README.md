# page23 ― 방향 출력 · 답변 문구 (A7 · A8 · R10) ― PJT01 완성

> 강의자료 **17 ~ 18쪽** (A7 · A8) · **19쪽** (화면) · **20 ~ 21쪽** (R10) / **23쪽** (실습 1-2) · **25쪽** (서버 로그)  ·  `AI코어프로젝트_3회차_DAY2_r2.pptx` (1일차 이어서)  ·  실행 위치: **PC**

move 를 라즈베리파이 OLED(LEFT · RIGHT)와 LED 로 좌우만 출력하고, 기기 탭 답변은 칸 수 없이 쓴다

## 무엇을 하는가

- [A7] `/api/robot-signal` {ip, direction} → 기기 D2 ― right → 17, left → 27, up · down 은 400 (화면이 부르지 않는다)
- [A8] `/api/oled-display` {ip, direction} → 기기 D3 ― left → LEFT … (R8)
- [R10] A5 요청에 ip 가 있으면(기기 탭) 문구만 '오른쪽으로 이동합니다.' ― tool · args · then 은 로컬 PC 탭과 같다
- 기기 탭 질문도 오늘은 PC LLM(Qwen3-4B)이 고른다. 기기 LLM 은 3일차 (page17 · page22)

## 실행

```bash
python 대시보드_기기연동.py        # http://127.0.0.1:8000 → 기기 탭
# 기기 탭 질문: '앞에 뭐가 있어?' · '오른쪽으로 3칸 가' · '위로 2칸 가' · '오른쪽 2칸 가고 위로 1칸' · '저쪽으로 가'
```

## 확인 포인트

- describe → 답변만, OLED · LED 그대로
- '오른쪽으로 3칸 가' → OLED RIGHT + 오른쪽 LED, 답변 '오른쪽으로 이동합니다.'
- '위로 2칸 가' → OLED · LED 출력 없음 (정상 ― 좌우만, up · down 은 심화)
- '오른쪽 2칸 가고 위로 1칸' → OLED RIGHT + 오른쪽 LED, 위로 1칸은 출력 없음
- '저쪽으로 가' → [추가 정보 요청], 다음 질문에서 이어받기
- 라즈베리파이 전원을 뽑아도 로컬 PC 탭은 그대로 (R6), 기기 탭 history 는 브라우저에 (R7)
