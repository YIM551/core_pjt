# page56 ― LLM 통합답변

> 강의자료 **56쪽** (코드) / **57쪽** (동작 결과)

인식 Text 세 줄 + 질문 → LLM(Qwen3-4B) 이 상황을 설명한다

## 무엇을 하는가

- 이 폴더의 perception.json (예시 인식 결과) 을 입력으로 쓴다 (없으면 내장 예시)
- 출처별 블록 + 출처 신뢰 규칙 + 사고 모드 끄기(/no_think)

## 실행

```bash
cd page56_LLM_통합답변
python LLM_통합답변.py
python LLM_통합답변.py --question "사람이 몇 명이야?"
python LLM_통합답변.py --rule "..."      # 규칙 한 줄 추가 (도전 문제 4)
```

## 확인 포인트

- 답에 방향(위) 이 [손 제스처] 근거대로 들어가면 성공
- 무엇을 말할지도 LLM 이 고른다 ― 실측에서는 tie(오탐)가 답에서 빠졌다
