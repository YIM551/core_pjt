# page45 ― 대시보드 서버

> 강의자료 **45쪽** (코드) / **46쪽** (동작 결과)

제공된 대시보드 화면(../../2회차_web)의 요청을 처리하는 API 를 만든다 ― 화면 + YOLO + VLM

## 무엇을 하는가

- GET / 와 /mediapipe/... 로 화면과 제스처 인식 파일을 내준다
- POST /api/yolo-detect : 이미지 → 객체 목록 (박스 좌표 포함)
- POST /api/vlm-describe : 이미지 → 장면 한 문장 (실습 1-2 규격, 긴 변 448px)
- 브라우저가 두 요청을 동시에 보내고, 서버는 run_in_threadpool 로 겹쳐 돌린다

## 실행

```bash
cd page45_대시보드_서버
python 대시보드_서버.py      # 띄워 둔다
# 브라우저에서 http://127.0.0.1:8000 → 대시보드 › 로컬 PC
# '앞에 보이는 이미지 설명해' 입력 → [전송]
```

## 확인 포인트

- 스냅샷 위에 YOLO 박스, VLM 칸에 한 문장이 뜨면 성공
- LLM 칸의 '오류' 는 정상 ― 실습 4-3 에서 /api/llm-answer 를 붙인다
- 서버 창의 [yolo] / [vlm] 로그에서 두 요청의 시작 시각이 같은지 본다
- html 파일을 직접 열면 동작하지 않는다 ― 반드시 서버 주소로 접속
