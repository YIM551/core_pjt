# page14 ― YOLO 텍스트요약

> 강의자료 **14쪽** (코드) / **15쪽** (동작 결과)

YOLO 검출 결과를 LLM 이 읽을 한 문장으로 요약한다

## 무엇을 하는가

- 좌표를 버리고 '무엇이 몇 개' 만 남긴다
- min_conf 0.0 / 0.5 / 0.8 로 요약이 어떻게 달라지는지 본다

## 실행

```bash
cd page14_YOLO_텍스트요약
python YOLO결과_텍스트요약.py
```

## 확인 포인트

- "person 4개, bus 1개" 형태의 한 문장이 나오면 성공
- min_conf 0.8 에서는 person 이 3개로 줄어든다 (노이즈 ↔ 누락)
