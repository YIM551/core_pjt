# 기능 구현 ③ ― VLM 단축측정

> 강의자료 **41쪽** (VLM 을 줄이는 레버) 의 표를 내 PC로 다시 잰다

VLM 응답 시간을 줄이는 레버(출력 / 입력)를 하나씩 측정한다

## 무엇을 하는가

- A 기준 → B 출력 줄이기(max_tokens 60) → C 입력 줄이기(이미지 448px)
- 측정 전에 작은 입력으로 워밍업 1회

## 실행

```bash
cd 과제_VLM_단축측정
python VLM_단축측정.py
```

## 확인 포인트

- 출력을 줄여도 거의 그대로, 이미지를 줄이면 약 4배 빨라진다
- PC마다 값이 다르다 ― 내 PC의 숫자를 남기는 것이 목적이다
- 웹 대시보드 서버(실습 3-1)는 설정 C 를 쓴다
