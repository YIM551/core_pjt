# page31 ― 제스처 방향판별

> 강의자료 **31쪽** (코드) / **32쪽** (동작 결과)

손목 → 검지 끝 벡터로 가리키는 방향을 판별하고 Text 로 만든다

## 무엇을 하는가

- pointing_up.jpg 를 0 / 90 / 180 / 270 도 돌려 네 방향을 만든다
- gesture 카테고리와 랜드마크 방향을 나란히 비교한다
- --save 로 회전별 방향(손목 → 검지 끝 화살표)을 그린 PNG 를 이 폴더에 저장한다

## 실행

```bash
cd page31_제스처_방향판별
python 제스처_방향판별.py --save
python 제스처_방향판별.py --mirror
```

## 확인 포인트

- 카테고리는 90° · 270° 에서 None, 180° 에서 Thumb_Down 으로 틀린다
- 랜드마크 방향은 위 → 왼쪽 → 아래 → 오른쪽으로 모두 맞는다
- --mirror 를 주면 좌우만 뒤집힌다 (셀카 카메라용)
