# page64 ― 대시보드 LLM연결

> 강의자료 **64쪽** (코드) / **65쪽** (동작 결과)

실습 3-1 서버에 /api/llm-answer 를 더해, 대시보드 질문에 LLM 이 답하게 한다

## 무엇을 하는가

- 화면이 보낸 질문 + YOLO 요약 + VLM 문장 + 손 방향으로 출처별 블록을 만든다
- 블록과 규칙은 실습 4-1 그대로, 응답은 {need_more_info, message, user_content}
- 오늘은 설명까지만 ― 도구 호출(로봇 이동)은 3일차

## 실행

```bash
cd page64_대시보드_LLM연결
python 대시보드_LLM연결.py    # 띄워 둔다
# 브라우저에서 http://127.0.0.1:8000 → 대시보드 › 로컬 PC
# '사람이 몇 명이야?' 입력 → [전송]
```

## 확인 포인트

- '사람이 몇 명이야?' 에 YOLO 개수(3명)로 답하면 성공 (VLM 은 '두 명')
- 서버 창에 LLM 입력 블록이 그대로 찍힌다
- 진행바의 '추가정보' · '이동중' 은 건너뛴다 ― 3일차에 채운다

## 이 폴더에 생기는 것

- 실행결과.txt ― 실제 실행 출력
- 실행화면.png ― 실제 대시보드 화면 (웹캠 대신 samples/sample.jpg)
